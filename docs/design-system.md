# ai-desk 视觉系统

更新于 2026-08-28。

## 1. 视觉主题

原生石墨工作台。界面保持紧凑、连续和低噪音，主要依靠背景明度阶梯建立层级，蓝色只承担操作、选中和运行状态。

## 2. 色彩角色

- `--bg-window` 到 `--bg-surface-raised`：六级石墨表面。
- `--text-primary` 到 `--text-disabled`：四级文本对比度。
- `--accent`：主操作、焦点、活动会话和运行状态。
- 强调色支持 8 个预设与自定义 Hex，深浅主题分别计算可读色值。
- `--success`、`--warning`、`--error`：运行与 Git 语义。
- 窗口背景透明度可在 72%～100% 范围调整，不降低文字和图标透明度。

## 3. 字体规则

- 界面字体：支持系统 UI、Geist Sans 与等宽字体，默认优先使用系统 UI 字体。
- 字体大小：基准 13px，可在 11px～16px 范围内以 0.5px 调整；所有文字尺寸从统一令牌派生。
- 正文：13px，行高 1.45；长回复：13px，行高 1.65。
- 工具栏与属性：10.5px 到 12.5px。
- 路径、命令、时间和代码：`--font-code`。

## 4. 组件样式

- 控件高度：24px、28px、32px 三档。
- 圆角：默认基准为 7px，并由一个全局设置同步派生 3px、5px、7px、9px 与输入器圆角；仅圆点和开关使用 pill。
- 按钮：100ms 颜色过渡，按下缩放到 0.96。
- 输入器：参考 Codex 的悬浮式任务输入器，12px 圆角；模型、思考深度和发送/停止按钮固定在 Tiptap 编辑面内部底部。
- 工作轨迹：5px 圆角、低对比边框、结构化状态行。

## 5. 布局原则

- macOS 使用 52px Overlay 沉浸式标题栏，原生红绿灯定位在 16×18px。
- 固定三栏：项目与会话、中间消息流、文件与 Git 检查器。
- 消息流与输入器共用响应式内容列，在 72ch 到 82ch 之间随中间工作区宽度连续变化，左右边界保持严格对齐。
- 页面与面板遵循 4px 间距网格。
- 不使用营销式 Hero、悬浮卡片和装饰性网格。

## 6. 层级

- 常驻面板使用背景阶梯，不使用投影。
- 普通输入器使用 `--control-shadow`，任务输入器使用 `--composer-shadow`。
- 弹层只使用 `--shadow-popover`。
- 选中会话使用强调色 tint 和 2px 内侧标记。

## 7. 约束

- 不在业务组件里重新定义按钮、输入框、标签页和菜单基础样式。
- 不使用蓝紫渐变、玻璃拟态和大圆角卡片。
- 不把强调色同时用于普通文件夹、正文和非关键装饰。
- 不保留无行为的可交互控件。
- 不使用 `transition: all`。
- 业务组件不得写死普通控件圆角，必须使用 `--radius-*` 令牌。
- 可交互元素必须显示对应鼠标形态；点击使用 pointer，文本编辑使用 text，禁用态使用 not-allowed。

## 8. 响应式

- 产品目标是最小 1024×640 的桌面窗口。
- 面板可拖动，但控件高度和文字尺度保持稳定。
- 中间工作区使用容器查询判断宽屏，不受左右面板宽度变化干扰。
- 1100px 以下降低看板娘占比和透明度。

## 9. 后续实现提示

- 新工具栏：36px 高，背景 `--bg-surface`，底部使用 `--border-subtle`。
- 新列表行：28px 或 32px 高，5px 圆角，悬停使用 `--bg-hover`。
- 新弹层：7px 圆角，背景 `--bg-surface-raised`，阴影 `--shadow-popover`。
- 新状态按钮：32px 方形，8px 圆角，按下缩放到 0.96。
